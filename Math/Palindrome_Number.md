Concepts:
- Integer Reversal
- Modulus (%)
- Integer Division (/)
- Digit Extraction

Pattern:
- Reverse Number

Key Formula:
reverse = reverse * 10 + digit

What I Learned:
- Extract last digit using %10
- Remove last digit using /10
- Build a reversed number
- Compare original and reversed numbers

Time Complexity:
O(log n)

Space Complexity:
O(1)
