## Approach

1. Remove all non-alphanumeric characters.
2. Convert everything to lowercase.
3. Use two pointers:

   * left starts at beginning
   * right starts at end
4. Compare characters while moving inward.
5. If any mismatch occurs, return false.
6. Otherwise return true.
