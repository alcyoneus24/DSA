# FizzBuzz

## Difficulty

Easy

## Concepts

- Loops
- Modulus Operator
- Conditions
- Vectors

## Approach

Traverse from 1 to n.

- If divisible by 3 and 5 -> FizzBuzz
- If divisible by 3 -> Fizz
- If divisible by 5 -> Buzz
- Otherwise -> number as string

## Time Complexity

O(n)

## Space Complexity

O(n)

## What I Learned

- push_back()
- to_string()
- Condition ordering
